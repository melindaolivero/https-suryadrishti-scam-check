# AI Fraud Protection Assistant for Seniors

## Overview
This project is an AI-powered fraud protection assistant designed to help seniors identify and respond to potential scams using natural language (voice or text). The system provides real-time scam risk analysis with simple, calming explanations and recommended next steps.

## Problem Statement
Seniors are increasingly targeted by digital scams including impersonation calls, phishing emails, and urgent payment requests. Most existing tools are either too technical or lack clear guidance for non-technical users.

## Solution
A conversational AI assistant that allows users to:
- Speak or type suspicious messages
- Receive scam risk analysis
- Understand why something may be suspicious
- Get simple, actionable next steps

## Key Features
- Voice input (speech-to-text)
- Text input interface
- AI-powered scam detection (Claude)
- Explainable results (risk + reasoning)
- Calm, senior-friendly UX design
- Trusted contact escalation concept (future feature)

## AI Model
Claude (Anthropic) is used to:
- Analyze user input
- Detect scam patterns
- Generate human-readable explanations
- Recommend safe actions

## UX Principles
- Calm and non-alarming tone
- Large, accessible UI
- Minimal cognitive load
- Trust-building language
- Step-by-step guidance

## Product Flow
1. User speaks or types message
2. System sends input to Claude API
3. Claude returns structured risk analysis
4. UI displays:
   - Risk level
   - Explanation
   - Suspicious indicators
   - Recommended actions

## Tech Stack
- Frontend: Lovable (AI-generated UI builder)
- AI: Claude (Anthropic API)
- Voice: Browser speech-to-text (Web Speech API)
- Hosting: Lovable preview environment
